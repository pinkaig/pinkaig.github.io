DigiPen Life

My Journey Through the RTIS Programme

Coming from a Diploma in Multimedia & Infocomm Technology at Nanyang Polytechnic, I joined the Real-Time Interactive Simulation degree run jointly by the Singapore Institute of Technology and DigiPen Institute of Technology. The programme pushes hard on the fundamentals such as data structures, computer graphics, math for games while expecting you to immediately apply them in engine and gameplay projects with a team, on a deadline.

One of the highlights so far was the Overseas Immersion Programme, where I spent a trimester at DigiPen's Europe-Bilbao campus in Spain. Working alongside professors and classmates from a completely different academic culture reshaped how I approach problems. I came back more comfortable pitching ideas, asking questions in unfamiliar settings, and collaborating with people who didn't necessarily share my first language.

Project Module

Inside Pulse Protocol: Building a Custom C++/OpenGL Engine

For my current project module, I'm working as a graphics programmer on Pulse Protocol, a 2D game engine built from scratch in C++ and OpenGL. My focus has been on the graphics-facing systems: the rendering pipeline, texture and font handling, animation, and wiring up UI through ImGui-based editor tools.

A big part of the work has been fitting these systems cleanly into our ECS architecture, so gameplay and tooling code can query and render entities without caring how the underlying graphics resources are managed. We use JSON serialization to save and load scene and entity data, which has also meant building small in-editor tools so the rest of the team can iterate without touching engine code directly.

The most valuable part of the module isn't just the rendering code, it's learning to build something a whole team can rely on: keeping the editor stable while the renderer is still changing underneath it, and communicating engine changes clearly so gameplay programmers aren't blocked.
